# Single-shot multi-slice spiral spatiotemporally encoded MRI with deep-learning-based referenceless distortion correction

## Overview

This repository contains the implementation materials for the MS-sSPEN MRI method, including the original VnmrJ sequence and spiral sampling code.

## Repository Structure

```text
MS-sSPEN/
├── README.md
├── VnmrJ_sequence/
│   ├── layout/                   # Sequence interface layouts
│   ├── parlib/                   # Parameter configurations
│   ├── protocols/                # Acquisition protocols
│   ├── psglib/                   # Pulse sequence programs
│   └── shapelib/                 # RF waveform files
└── Spiral Sampling/              # Spiral trajectory generation code
```
